# WieLult 🍆

React + Vite app voor WieLult.

## Start

```bash
npm install
npm run dev
```

## Status

**Bèta 0.1: mobiele interface, speluitleg, spelersnaam en host-instellingen.** Dit is nog geen volledig speelbaar multiplayer-spel. De huidige kamercode is een lokale demonstratie en kan nog niet door andere telefoons worden gebruikt. De database en realtime gameplay volgen.

## Beveiliging

De frontend gebruikt alleen een publieke Supabase publishable key. Geheime woorden, rollen, stemmen en scoreberekening moeten in beveiligde serverfuncties worden verwerkt; niet in publiek leesbare tabellen.
